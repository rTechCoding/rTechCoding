# rTechCoding Professional GitHub README

## Included
- README.md — complete professional profile README
- .github/workflows/snake.yml — animated contribution snake workflow
- SETUP.md — installation instructions

## Installation
1. Open your GitHub profile repository named exactly `rTechCoding`.
2. Upload `README.md` to the repository root.
3. Upload the `.github` folder.
4. Commit and push the files.
5. Open the Actions tab and run **Generate Contribution Snake** once if needed.

## Important
GitHub profile README files support Markdown, badges, SVGs, GIFs, images and limited HTML. They do not support arbitrary custom CSS or JavaScript.

This package uses working GitHub-compatible animation and live widgets:
- Animated typing SVG
- GitHub statistics
- Top languages
- Contribution streak
- Contribution graph
- Contribution snake animation
